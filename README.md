# 40th Millennium Tabletop Companion
**Author:** btran0014

## What is 40th Millennium Tabletop Companion (40MTtC)?
40th Millennium Tabletop Companion (40MTtC) is a tabletop gaming app designed for **Warhammer 40,000** players that streamlines army list building, live match point tracking, and probability based combat simulations. 

## Goals to reach through 40MTtC?
- Clean software and database architecture development
- Understanding of basic web development processes
- RESTful API design
- C# development using ASP.NET framework and EntityFrameworkCore ORM
- PostgreSQL database development in C# using EFCore
- Linux command line and shell scripting skills via WSL
- Containerization using Docker
- API testing using Postman
- E2E testing using Playwright
- Automation and CI/CD pipelines using Github Actions
